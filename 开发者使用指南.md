### 3. Error Boundary (`archium/ui/error_boundary.py`)

#### 使用装饰器
```python
from archium.ui.error_boundary import with_error_handling

@with_error_handling
def load_project_data(project_id):
    # 可能抛出错误的代码
    data = fetch_from_database(project_id)
    return data
```

#### 使用上下文管理器
```python
from archium.ui.error_boundary import ErrorBoundary

with ErrorBoundary("加载项目数据"):
    project = load_project(project_id)
    process_data(project)
# 如果出错，会自动显示友好的错误消息
```

#### 安全执行
```python
from archium.ui.error_boundary import safe_execute

# 出错时返回默认值，不中断程序
data = safe_execute(
    load_data,
    project_id,
    fallback_value=[],
    error_message="无法加载数据，使用默认值",
)
```

#### 错误翻译
```python
from archium.ui.error_boundary import ErrorTranslator

# 将技术错误翻译为用户友好的消息
translation = ErrorTranslator.translate(exception)
print(translation["title"])        # "项目不存在"
print(translation["message"])      # "该项目可能已被删除..."
print(translation["suggestions"])  # ["返回项目列表...", ...]
```

## 🎨 使用模式

### 模式 1: 标准页面模板

```python
def render() -> None:
    from archium.ui.components.navigation import (
        render_workflow_progress_indicator,
        render_stage_navigation_hint,
        set_current_stage,
    )
    from archium.ui.error_boundary import ErrorBoundary

    # 1. 设置阶段
    set_current_stage("materials")

    # 2. 显示进度
    render_workflow_progress_indicator("materials")

    # 3. 页面头部
    st.title("资料管理")
    st.caption("上传和整理项目资料")

    # 4. 主要内容（带错误处理）
    with ErrorBoundary("加载资料列表"):
        materials = load_materials()
        display_materials(materials)

    # 5. 下一步提示
    render_stage_navigation_hint("materials")
```

### 模式 2: 使用标签页组织复杂内容

```python
def render() -> None:
    st.title("项目工作台")

    # 不要用多个 expander，用标签页
    tab1, tab2, tab3 = st.tabs(["📁 资料", "🔍 诊断", "⚙️ 高级"])

    with tab1:
        st.caption("日常资料管理")
        render_materials_tab()

    with tab2:
        st.caption("高级诊断工具")
        # 可以嵌套二级标签页
        diag_tabs = st.tabs(["检索", "分块", "冲突"])
        with diag_tabs[0]:
            render_rag_preview()

    with tab3:
        st.caption("高级功能")
        render_advanced_features()
```

### 模式 3: 列表页面模板

```python
def render_project_list() -> None:
    from archium.ui.components.enhanced_ui import (
        render_empty_state,
        render_action_card,
    )

    projects = load_projects()

    if not projects:
        render_empty_state(
            title="暂无项目",
            description="创建第一个项目开始使用",
            icon="📭",
            action_label="创建项目",
            on_action=create_project,
        )
        return

    for project in projects:
        render_project_card(project)
```

### 模式 4: 队列/状态页面模板

```python
def render_queue() -> None:
    from archium.ui.components.enhanced_ui import (
        render_progress_card,
        render_status_indicator,
    )

    items = load_queue_items()
    completed = [i for i in items if i.status == "complete"]
    failed = [i for i in items if i.status == "failed"]

    # 显示总体进度
    render_progress_card(
        title="处理进度",
        current=len(completed),
        total=len(items),
        details=f"失败 {len(failed)} 项",
    )

    # 分组显示
    if failed:
        st.markdown("**❌ 需要处理**")
        for item in failed:
            render_queue_item(item, show_actions=True)

    with st.expander(f"✅ 已完成 ({len(completed)})", expanded=False):
        for item in completed:
            render_queue_item(item, show_actions=False)
```

## 🚫 反模式（避免）

### ❌ 不要直接使用 st.error()
```python
# 不好
try:
    load_data()
except Exception as e:
    st.error(str(e))  # 用户看不懂技术错误

# 好
from archium.ui.components.enhanced_ui import render_error_message

try:
    load_data()
except Exception as e:
    render_error_message(
        e,
        title="加载失败",
        action_label="重试",
        on_action=retry,
    )
```

### ❌ 不要堆叠多个 expander
```python
# 不好 - 需要大量滚动
with st.expander("功能1"):
    render_feature1()
with st.expander("功能2"):
    render_feature2()
with st.expander("功能3"):
    render_feature3()

# 好 - 使用标签页
tab1, tab2, tab3 = st.tabs(["功能1", "功能2", "功能3"])
with tab1:
    render_feature1()
```

### ❌ 不要混用不同的状态表示
```python
# 不好 - 不一致
st.markdown("✅ 完成")
st.markdown("❌ 失败")
st.markdown("⏳ 进行中")

# 好 - 使用统一组件
render_status_indicator("success", "完成")
render_status_indicator("error", "失败")
render_status_indicator("pending", "进行中")
```

## 📋 迁移检查清单

将旧页面迁移到新组件库时，检查以下项：

- [ ] 引入并设置当前阶段 (`set_current_stage`)
- [ ] 显示五阶段进度条 (`render_workflow_progress_indicator`)
- [ ] 使用标签页组织复杂内容（替代多个 expander）
- [ ] 使用 `render_error_message` 替代 `st.error()`
- [ ] 使用 `render_status_indicator` 统一状态显示
- [ ] 使用 `render_progress_card` 显示进度
- [ ] 列表为空时使用 `render_empty_state`
- [ ] 任务入口使用 `render_action_card`
- [ ] 添加 `ErrorBoundary` 或 `@with_error_handling`
- [ ] 页面末尾添加导航提示 (`render_stage_navigation_hint`)

## 💡 常见问题

### Q: 为什么要用标签页而不是 expander？
A: 标签页更适合平级的功能模块，减少滚动。Expander 适合补充信息或不常用功能。

### Q: 什么时候用 ErrorBoundary，什么时候用装饰器？
A: 
- 装饰器 (`@with_error_handling`): 适合单个函数
- 上下文管理器 (`with ErrorBoundary`): 适合代码块
- `safe_execute`: 适合需要返回默认值的情况

### Q: 如何自定义错误翻译？
A: 在 `ErrorTranslator._translations` 中添加新的映射：
```python
ErrorTranslator._translations["MyCustomError"] = {
    "title": "自定义错误",
    "message": "这是自定义的错误消息",
    "suggestions": ["建议1", "建议2"],
}
```
