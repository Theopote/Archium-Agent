# 用户概念映射关系

用户可感知对象压缩为五类：**项目 / 资料 / 方案 / 汇报 / 交付**。  
内部领域对象全部隐藏在这五类后面；侧栏制作链仍用可区分的阶段名，避免两个入口同名。

## 制作五阶段（侧栏导航）

当前 canonical 导航（与 `product_flow.py` / Playbook E 一致）：

`资料 → 大纲 → 生成 → 工作室 → 交付`

| 阶段 | 用户概念归属 | 说明 |
|------|--------------|------|
| 资料 | 资料 | 上传与整理项目资料 |
| 大纲 | 汇报（结构） | 确认故事线与页序；勿与「方案探索」混名 |
| 生成 | 汇报（内容） | 产出页面内容 |
| 工作室 | 汇报（编辑） | 选中、改稿、撤销、版式 |
| 交付 | 交付 | 导出与质量检查 |

「方案」作为用户概念，主要落在隐藏深链（概念探索 / 项目任务），不占用侧栏与「大纲」抢名。

## 首页四入口（任务，非流程）

首页只面对任务，不推销系统五阶段。入口固定为：

| 入口 | 行为 |
|------|------|
| 新项目 | `project-genesis` 常规理解路径 |
| 打开已有项目 | 项目管理 / 继续最近项目 |
| 快速生成一份汇报 | Genesis `genesis_intent=fast_deck`（少追问、可直达工作室预览） |
| 使用单项工具 | `tool-hub` 工具台 |

工具台挂载已有能力（页面复活、模板库、大纲、工作室、资料事实核对等）；尚未独立成页的能力（PDF 提指标、识扫描图、草图分析图）仅作诚实占位并指向资料路径。完整工作流与单项工具共享 application 服务，UI 不强迫创建 Mission。

可解释 NBA（Next Best Action）在知识条与 Genesis「下一步」展示：建议做什么、为什么现在做、会影响什么、预计结果、可否撤销。

## 五大用户概念

### 1. 项目
用户对整个设计项目的理解和管理。

**内部对象 → 用户界面表达：**
- `KnowledgeState` → 项目理解程度
- `ProjectContext` → 当前项目状态
- `ProjectMission` → 本次设计任务
- `Project` → 项目

### 2. 资料
项目相关的所有资料和文档。

**内部对象 → 用户界面表达：**
- `Asset` → 资料
- `Document` → 文档
- `Reference` → 参考资料
- `AssetBoard` → 资料库

### 3. 方案
设计方案的探索和确定。

**内部对象 → 用户界面表达：**
- `ConceptDirection` → 方案方向
- `SceneProposal` → 方案提案
- `ConceptExploration` → 方案探索
- `DesignConcept` → 设计概念

### 4. 汇报
汇报内容的组织和编辑。

**内部对象 → 用户界面表达：**
- `Storyline` → 汇报结构（侧栏：**大纲**）
- `SlideSpec` → 页面内容（侧栏：**生成**）
- `LayoutPlan` → 页面版式（侧栏：**工作室**）
- `RenderScene` → 可编辑页面（侧栏：**工作室**）
- `Presentation` → 汇报
- `Slide` → 幻灯片

### 5. 交付
最终成果的生成和导出。

**内部对象 → 用户界面表达：**
- `Workstream` → 工作内容
- `DeliverablePlan` → 预期成果
- `Deliverable` → 交付成果
- `Export` → 导出

## 隐藏的系统术语

以下系统术语不应在用户界面中出现：

### 知识管理相关
- ❌ `KnowledgeDimensions` → 使用"项目理解维度"
- ❌ `ProcessBoard` → 使用"工作流程"
- ❌ `KnowledgeProfile` → 使用"项目知识档案"

### 场景管理相关
- ❌ `SceneProposal` → 使用"方案提案"
- ❌ `SceneRevision` → 使用"方案版本"
- ❌ `SceneContext` → 使用"方案背景"

### 工作流相关
- ❌ `WorkflowRun` → 使用"生成任务"
- ❌ `WorkflowCheckpoint` → 使用"任务进度"
- ❌ `WorkflowState` → 使用"任务状态"

### 视觉相关
- ❌ `VisualWorkflowResult` → 使用"视觉生成结果"
- ❌ `RenderScene` → 使用"可编辑页面"
- ❌ `LayoutPlan` → 使用"页面版式"

### 质量相关
- ❌ `QualityAssessment` → 使用"质量评估"
- ❌ `CritiqueReport` → 使用"评审报告"
- ❌ `QAReport` → 使用"质量报告"

## 界面术语替换规则

### 导航和菜单
- "工作流" → "生成"
- "场景" → "方案"
- "知识" → "项目理解"
- "资产" → "资料"
- "交付物" → "交付成果"
- 侧栏禁止出现两个同名「汇报」入口；用 **生成** / **工作室** 区分

- "生成工作流" → "生成汇报"
- "创建场景" → "创建方案"
- "上传资产" → "上传资料"
- "导出交付物" → "导出成果"

- "工作流运行中" → "生成进行中"
- "场景已创建" → "方案已创建"
- "资产已上传" → "资料已上传"
- "交付物已生成" → "成果已生成"

- "工作流面板" → "生成面板"
- "场景面板" → "方案面板"
