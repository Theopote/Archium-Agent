## 使用说明

### 启用完整交互编辑功能
要启用Canvas Editor的完整交互编辑功能，运行：
```bash
cd archium/ui/components/canvas_editor
bash build.sh
```

### 使用设计系统面板
1. 打开工作室页面
2. 在右侧检查器中选择"设计系统"标签
3. 使用各项功能：
   - 选择并应用专业模板
   - 优化当前幻灯片布局
   - 评估设计质量
   - 搜索视觉元素
