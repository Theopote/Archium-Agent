# v0.2 Beta 发布决策

> **最后更新：** 2026-08-05  
> **决策：** ⛔ **暂不发布 Beta 标签**（工程收敛 + 真人闭环未齐；**另加 Visual Quality Recovery 硬门**）  
> **验收基线：** `v0.2-alpha-rc1-candidate` → `a81a0b88302a7c4c25c888facb672e82aec290b0`（冻结中）  
> **产品主线：** [`docs/roadmap/architectural-visual-quality-recovery-p0.md`](roadmap/architectural-visual-quality-recovery-p0.md) — **VQ-008 建筑师盲评未达标前禁止打 Beta**

## 版本语义（本文范围）

请区分三条并行语义线（详见 [文档中心](README.md#版本语义避免混用)）：

| 语义线 | 当前标识 | 本文是否约束 |
|--------|----------|:------------:|
| **Software version** | `v0.2.x-alpha` → 目标 `v0.2-beta` 标签 | ✅ |
| **Presentation Engine version** | `v0.3` | ❌ 见 [Presentation Engine v0.3](roadmap/presentation-engine-v0.3.md) |
| **Product milestone** | Showcase Candidate 1 | ❌ 见 [能力矩阵](release-capability-matrix.md) |

**Presentation Engine v0.3** 或 **Showcase Candidate 1** 的进展，**不能**单独作为打 `v0.2-beta` 软件标签的依据；反之，软件 Beta 标签也不代表 Showcase 已可对外交付。

## 一句话

Beta 不是「工程师觉得可以了」，而是「非开发用户在真实项目上走通主链，修改成本可量化，且输出具备建筑师认可的视觉表达」。当前 **B10 未完成**、**远端 CI 绿未由本环境证实**，且 **VQ-008 盲评未启动**，因此 **不能** 打 `v0.2-beta` 标签。

真人反馈已收敛为「排版不够好看」——在 Visual Quality Recovery（VQ-001…VQ-008）达到盲评门槛前，**暂停 Beta 冲刺**，视觉质量为唯一产品主线。

VQ-008 基建（协议 / 计分 / `evaluate_vq008_blind_review.py`）已落地，见 [`vq008-architect-blind-review-protocol.md`](roadmap/vq008-architect-blind-review-protocol.md)；**≥5 名建筑师真人盲评未执行前，`beta_allowed` 仍为 false。**

## RC 冻结（`v0.2-alpha-rc1-candidate`）

| 项 | 值 |
|----|-----|
| **Tag** | `v0.2-alpha-rc1-candidate` |
| **Freeze SHA** | `a81a0b88302a7c4c25c888facb672e82aec290b0` |
| **冻结起点** | 2026-08-04 |
| **建议冻结窗** | 5–7 天（或直至 Linux CI 连续 3 次绿 + Windows nightly ≥1） |
| **目的** | 工程验收 + 真人验收；避免基线漂移导致证据失效 |

### 冻结期内禁止

- 大规模 SessionLike / Unit of Work 重构（与 VQ 无关）
- 新页面、新 Agent、协作扩面
- 界面美化（芯片、配色、动画、更多工具入口等）
- **打 `v0.2-beta` 标签**（直至 B10 + VQ-008）

### 冻结期内仅允许

- CI 修复（lock-sync、Ruff、Mypy、单测/集成、coverage、golden/smoke）
- 事务错误、数据损坏、启动失败、导出失败
- Alembic / Streamlit / Canvas 启动与迁移失败
- 真人测试 blocker、严重 UI 阻塞
- 安全审计 enforcement 预演相关修复（目标：早于 **2026-08-08**）
- **本文档**与验收记录的更新
- **Visual Quality Recovery（VQ-001…VQ-007）** 及 Scene SSOT（RS-003）——见 [P0 VQR](roadmap/architectural-visual-quality-recovery-p0.md)；此类变更可新增 Domain/API，但必须服务正式画面气质，禁止平行造新 Agent

### 通过标准（工程）

- Linux 主 CI 在冻结 SHA（或其仅含上述允许修复的后代）上 **连续 3 次全绿**
- Windows nightly **至少 1 次全绿**
- Alembic：空库 upgrade head + 自上一 revision 增量均成功
- 无已知 flaky test；安全审计在强制日前完成一次 enforcement dry-run

### 通过标准（人工，工程绿之后）

- 至少 1 名非开发用户完成剧本 A 主链
- 剧本 E（工作室 HITL）真人完成（工程预演 ≠ 真人）
- 有可量化修改成本（`edit_minutes` / session CSV）
- **VQ-008**：≥5 名建筑师盲评达标（新版对旧版胜率 ≥80%；可直接用/轻改 ≥60%；均分 ≥7/10；改稿时间 ↓≥50%）——详见 [P0 VQR](roadmap/architectural-visual-quality-recovery-p0.md)

## 何时可以打 Beta 标签

**全部满足**时，将 `pyproject.toml` / README 版本升为 `v0.2-beta.1` 并打 git tag `v0.2-beta.1`：

1. 上表 **剩余 Beta blocker** 全部为 ✅；
2. `summarize_beta_rehearsal.py` 输出中 `participants_non_dev >= 1` 且 `total_edit_minutes > 0`；
3. `beta_blocker` 开放 issue 数为 **0**；
4. `master` 上 CI + Windows nightly 连续绿 ≥3 天（或 RC tag 上全绿）。
