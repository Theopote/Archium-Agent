# Archium v1.0 Final Architecture — Composition-Driven Visual Planning

**Version**: v1.0 (目标架构)  
**Current**: v0.3 (已实施双轨并行)  
**Migration Path**: 5-phase gradual deprecation

---

## 核心原则

1. **内容 ≠ 风格** — 同一内容可以有多种视觉表达
2. **单一路径** — 只有 composition-driven，无 legacy fallback
3. **LayoutFamily 内部化** — 不暴露给 LLM 或用户
4. **多风格支持** — BIG/SOM/OMA 等不同视觉语言
5. **可执行判断** — 结构化策略，不是文字描述

## v1.0 核心模型

### 1. PageType（内容类型）— 必需

```python
class PageType(StrEnum):
    """Pure content classification."""
    COVER = "cover"
    SECTION_OPENER = "section_opener"
    SITE_ANALYSIS = "site_analysis"
    STRATEGY = "strategy"
    EVIDENCE = "evidence"
    COMPARISON = "comparison"
    TECHNICAL_DRAWING = "technical_drawing"
    DATA_METRICS = "data_metrics"
    TEXT_ARGUMENT = "text_argument"
    # ... 19 types total
```

**特性**:
- ✅ 描述"这是什么内容"
- ✅ 与视觉风格解耦
- ✅ LLM 易于理解（不需要记忆模板）

### 2. CompositionStrategy（构图策略）— 必需

```python
@dataclass
class CompositionStrategy:
    """Structured design judgment."""
    
    # High-level archetype
    archetype: str  # "architectural_editorial", "hero_statement", etc.
    
    # Composition structure
    dominant_axis: CompositionAxis
    focal_point: tuple[float, float] | None
    reading_path: ReadingPathType
    
    # Visual forces
    tension: VisualTension
    balance: VisualBalance
    
    # Element roles
    image_role: ImageRole
    typography_role: TypographyRole
    
    # Spatial strategy
    white_space: WhiteSpaceStrategy
    margins: MarginsStrategy
    layering: LayeringStrategy
    
    # Architectural-specific
    drawing_priority: float  # 0-1
    precision_level: str
    annotation_density: str
```

**特性**:
- ✅ 可执行的设计判断（不是文字描述）
- ✅ 建筑师思维模型（轴线、张力、平衡）
- ✅ 支持多种视觉语言

### 3. StylePreset（视觉风格）— v1.1

```python
class StylePreset(StrEnum):
    """Office-specific visual language presets."""
    BIG_BOLD = "BIG_bold"
    SOM_MINIMAL = "SOM_minimal"
    OMA_COLLAGE = "OMA_collage"
    MVRDV_COLORFUL = "MVRDV_colorful"
    # ... extensible
```

**应用层级**:
```python
# ArtDirection (deck-level)
art_direction.style_preset_id = "BIG_bold"

# DesignSystem overlay
design_system = apply_style_preset_overlay(
    base_system,
    style_preset_id="BIG_bold",
)
# → 修改 font_weights, color_intensity, margins, etc.
```

### 4. LayoutFamily（内部实现）— 不暴露

```python
class LayoutFamily(StrEnum):
    """Internal implementation detail — NOT exposed to LLM or UI."""
    HERO = "hero"
    EVIDENCE_BOARD = "evidence_board"
    DRAWING_FOCUS = "drawing_focus"
    # ... 10 families total
```

**v1.0 角色**:
- ✅ Registry 内部映射使用
- ✅ Generator 实现标识
- ✅ 调试和日志
- ❌ **不再暴露给 LLM**
- ❌ **不再暴露给用户 UI**

## v1.0 数据流

### LLM 生成 VisualIntent

```json
{
  "page_type": "strategy",
  "composition_strategy": {
    "archetype": "architectural_editorial",
    "dominant_axis": "horizontal",
    "reading_path": "z_pattern",
    "tension": "asymmetric",
    "balance": "left_weighted",
    "image_role": "dominant",
    "typography_role": "editorial",
    "white_space": "generous"
  },
  "communication_goal": "展示设计策略",
  "audience_takeaway": "理解三大设计原则"
}
```

**注意**: ❌ **不再生成** `preferred_layout_families`

### Registry 内部映射

```python
# v1.0: 用户/LLM 不知道 LayoutFamily

registry.candidates_for_composition(
    page_type="strategy",
    composition_strategy=CompositionStrategy(...),
    asset_count=1,
)

# Internal logic:
if composition.is_hero_dominated():
    return [LayoutFamily.HERO]  # 内部决策
elif composition.is_editorial_style():
    return [LayoutFamily.HYBRID_CANVAS]
# ...
```

### Generator 执行

```python
# Generator 仍然使用 LayoutFamily（内部）

generator = get_generator(LayoutFamily.HERO)  # internal
plan = generator.generate(context)
```

## v1.0 vs. v0.3 对比

| 维度 | v0.3（当前） | v1.0（目标） |
|------|-------------|-------------|

| **多风格支持** | ✅ 支持 | ✅ 支持 |
| **维护复杂度** | 高（双轨） | 低（单轨） |

## v1.0 关键 API 变化

### VisualIntent（Breaking Change）

```python
# v0.3
class VisualIntent:
    page_type: PageType | None = None  # optional
    composition_strategy: CompositionStrategy | str | None = None  # optional
    preferred_layout_families: list[LayoutFamily] = []  # legacy

# v1.0
class VisualIntent:
    page_type: PageType  # REQUIRED
    composition_strategy: CompositionStrategy  # REQUIRED, no str
    # ❌ REMOVED: preferred_layout_families
```

### LayoutFamilyRegistry（Breaking Change）

```python
# v0.3
class LayoutFamilyRegistry:
    def candidates_for(content_type, ...) -> list[...]:
        """Legacy method"""
    
    def candidates_for_composition(...) -> list[...]:
        """New method"""

# v1.0
class LayoutFamilyRegistry:
    def candidates_for_composition(...) -> list[...]:
        """Only method"""
    
    # ❌ REMOVED: candidates_for(content_type, ...)
```

### LLM Schema（Breaking Change）

```python
# v0.3
class VisualIntentDraft:
    page_type: str | None
    composition_strategy: dict | str | None
    preferred_layout_families: list[str]  # still generated

# v1.0
class VisualIntentDraft:
    page_type: str  # required
    composition_strategy: dict  # required, structured only
    # ❌ REMOVED: preferred_layout_families
```

## v1.0 示例：同一内容 × 不同风格

### 场景：策略页

```python
page_type = PageType.STRATEGY
content = {
    "title": "设计策略",
    "key_points": ["原则一", "原则二", "原则三"],
    "hero_image": "concept_diagram.jpg",
}
```

### BIG 风格

```python
intent_big = VisualIntent(
    page_type=PageType.STRATEGY,
    composition_strategy=CompositionStrategy(
        archetype="hero_statement",
        dominant_axis=CompositionAxis.NONE,
        reading_path=ReadingPathType.FOCAL_RADIAL,
        tension=VisualTension.DYNAMIC,
        balance=VisualBalance.CENTERED,
        image_role=ImageRole.DOMINANT,
        typography_role=TypographyRole.HERO,
        white_space=WhiteSpaceStrategy.GENEROUS,
    ),
)
# → Registry internal: LayoutFamily.HERO
# → 输出：巨大图片、动态张力、强烈色彩
```

### SOM 风格

```python
intent_som = VisualIntent(
    page_type=PageType.STRATEGY,
    composition_strategy=CompositionStrategy(
        archetype="architectural_editorial",
        dominant_axis=CompositionAxis.HORIZONTAL,
        reading_path=ReadingPathType.Z_PATTERN,
        tension=VisualTension.ASYMMETRIC,
        balance=VisualBalance.LEFT_WEIGHTED,
        image_role=ImageRole.SUPPORTING,
        typography_role=TypographyRole.EDITORIAL,
        white_space=WhiteSpaceStrategy.GENEROUS,
    ),
)
# → Registry internal: LayoutFamily.HYBRID_CANVAS
# → 输出：网格系统、严格留白、技术感
```

### OMA 风格

```python
intent_oma = VisualIntent(
    page_type=PageType.STRATEGY,
    composition_strategy=CompositionStrategy(
        archetype="collage",
        dominant_axis=CompositionAxis.NONE,
        reading_path=ReadingPathType.LAYERED,
        tension=VisualTension.DYNAMIC,
        balance=VisualBalance.ASYMMETRIC,
        image_role=ImageRole.SUPPORTING,
        typography_role=TypographyRole.DATA_LABEL,
        white_space=WhiteSpaceStrategy.COMPACT,
        layering=LayeringStrategy.PRONOUNCED,
    ),
)
# → Registry internal: LayoutFamily.HYBRID_CANVAS (different variant)
# → 输出：拼贴、高密度、冲突张力
```

**关键**: 用户/LLM 不需要知道内部使用了哪个 LayoutFamily

## v1.0 迁移路径

详见 [`legacy-path-deprecation-plan.md`](legacy-path-deprecation-plan.md)

**5 Phases**:
1. **Phase 1**: 监控（当前）✅
2. **Phase 2**: 批量迁移（50%+ 使用率）
3. **Phase 3**: Soft deprecation（60-80% 使用率）
4. **Phase 4**: Hard deprecation（80-90% 使用率）

## v1.0 收益

### 架构简化

- ✅ **单一路径** — 从双轨变为单轨
- ✅ **代码减少** — 移除 legacy fallback 逻辑
- ✅ **易于理解** — 新用户无困惑

### LLM 友好

- ✅ **不需要记忆** LayoutFamily 枚举
- ✅ **输出更简洁** — 只生成 PageType + CompositionStrategy
- ✅ **语义清晰** — "策略页" vs "STRATEGY_CARDS family"

### 用户体验

- ✅ **更直观** — 选择"内容类型"和"风格"，不选"模板"
- ✅ **更灵活** — 同一内容可以有多种表达
- ✅ **更专业** — 符合建筑师思维模式

### 可扩展性

- ✅ **新增风格容易** — 添加 StylePreset，不修改 LayoutFamily
- ✅ **新增内容类型容易** — 添加 PageType，不新增 Family
- ✅ **组合数可控** — 19 × 10 × 5 = 950（vs 150 固定模板）

## v1.0 风险与缓解

### 风险 1: Breaking Changes

**影响**:
- 需要更新所有现有数据
- 需要更新 LLM prompts
- 需要更新 UI

**缓解**:
- 5-phase 渐进式迁移
- 自动迁移工具
- 充分的 soft deprecation 期

### 风险 2: 用户抵制

**影响**:
- 用户习惯了旧路径
- 可能不理解为什么改变

**缓解**:
- 清晰的文档和示例
- "为什么迁移"的说明
- 提供自动迁移工具

### 风险 3: 质量回退

**影响**:
- 新路径可能不如旧路径稳定
- 用户可能发现布局质量下降

**缓解**:
- Phase 1-2 充分监控和验证
- Golden Case 回归测试
- 可以回滚（Phase 4 之前）

## 总结

### v1.0 核心价值

```
PageType（内容）+ CompositionStrategy（构图）+ StylePreset（风格）
↓
LayoutFamily（内部）
↓
LayoutPlan（几何）
```

**关键改变**:
1. ✅ **LayoutFamily 内部化** — 不再暴露
2. ✅ **单一路径** — 只有 composition-driven
3. ✅ **多风格支持** — BIG/SOM/OMA
4. ✅ **架构简化** — 更易维护

**最终状态**:
- 用户选择：**内容类型** + **视觉风格**
- LLM 生成：**PageType** + **CompositionStrategy**
- 系统执行：**内部映射 LayoutFamily** → **LayoutPlan**

Archium 成为真正的**建筑设计系统**，而不是"PPT 模板引擎"。
